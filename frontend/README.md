# frontend

Everything a browser is served.

| Path | Holds |
|---|---|
| `portals/<portal>/{views,public}` | the five portals: `eprisons`, `cctns`, `eforensics`, `aadhaar`, `ecourts` |
| `platform-hub/views/platform/` | hub, login, register and account pages shared by all five portals |
| `erp-console/views/` | the ERP console pages |

The e-Prisons views embed the supplied images as base64 partials in
`portals/eprisons/views/partials/img/` (generated by `backend/scripts/embed-eprisons-images.js`).
The e-Forensics views embed the captured images as base64 partials in
`portals/eforensics/views/partials/img/` (generated by `backend/scripts/embed-eforensics-images.js`).

`backend/platform-api` and the replica servers read a portal's views from
`portals/<portal>`. If that directory is missing they fall back to the copy in
`backend/gov_replica/<Category>/<host>/replica/frontend`.
